# Photos for RushiTech.AI

The site ships with original illustrations. To use **real, cinematic photos**, add a photo with the exact file name below and it replaces the illustration everywhere it is used. Nothing else needs changing.

## How to add photos
1. Get photos that are free to use commercially without attribution, for example from Pexels, Unsplash or Pixabay (check each photo's license), or generate them with an AI image tool you have rights to use.
2. Name each file exactly like the **Name** column (for example `slide-automate.jpg`).
3. Put the files in the `photos-input/` folder.
4. Run `npm run photos` (resizes to 1600px wide and compresses into `public/photos/`).
5. Commit and deploy. Missing photos keep their illustration, so you can add them gradually.

Tips: landscape 16:9, no text or logos in the photo, similar colour grading (cool blue/teal tones look best with the site design), ideally under 5 MB each before optimising.

AI prompt template: *"Photorealistic cinematic photograph of <subject>, shallow depth of field, soft natural light, teal and blue colour grading, 16:9, no text, no logos"*
