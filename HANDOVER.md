## Deploying changes
1. Edit the code, then `git add -A`, `git commit`, `git push origin main` (as Ru1221).
2. Render does **not** deploy automatically. Open the service, **Manual Deploy → Deploy latest commit**. It takes about 2 minutes.
3. If you change `lib/seed.ts`, bump `SEED_VERSION` in `lib/db.ts` so untouched rows update on the next start.

Local run: `npm install`, copy `.env.example` to `.env.local` and fill it in, then `npm run dev`.
